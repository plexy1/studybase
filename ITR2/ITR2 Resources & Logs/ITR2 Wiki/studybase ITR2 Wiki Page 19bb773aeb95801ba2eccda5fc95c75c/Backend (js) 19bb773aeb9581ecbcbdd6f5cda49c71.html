1. login.js

This is a JavaScript file that integrates Firebase Authentication into a web application. Here's a breakdown of what it does:

1. Firebase Setup

  • It imports Firebase SDK modules (firebase-app.js and firebase-auth.js) from Google's CDN.
  • Defines Firebase configuration with keys like apiKey, authDomain, projectId, etc.
  • Initializes Firebase using initializeApp(firebaseConfig).
  • Retrieves the authentication instance using getAuth(app).

2. User Authentication (Sign-In)

  • It waits for the DOM to load (DOMContentLoaded event).
  • Selects the login form and listens for its submit event.
  • On form submission:
    • Prevents the default form submission behavior (e.preventDefault()).
    • Retrieves email and password entered by the user.
    • Tries to sign in using signInWithEmailAndPassword(auth, email, password).
    • If authentication succeeds, the user is redirected to "search-topic.html".
    • If authentication fails, an error message is displayed in the signInMessage element.

3. Error Handling

  • If an error occurs during login, it:
    • Retrieves the error code and message.
    • Displays the error message in the signInMessage element.

Purpose

This script is designed to handle user login using Firebase Authentication in a web app. It securely verifies credentials and redirects users upon successful authentication while displaying errors if login fails.

2. firebaseauth.js

This JavaScript file handles Firebase authentication and Firestore database operations for user registration. Here's a breakdown of what it does:

Overview:

  • It integrates Firebase authentication and Firestore database.
  • It allows users to sign up using an email and password.
  • It stores additional user details (username and university) in Firestore.
  • It provides real-time feedback (success or error messages).
  • It redirects the user to a login page upon successful registration.

Key Functionalities:

  1. Firebase Initialization:
    • It imports Firebase modules for authentication and Firestore.
    • It initializes Firebase using a provided configuration.
  1. Handling User Registration:
    • Listens for the submit event on a form (registerForm).
    • Prevents default form submission behavior.
    • Captures user inputs (username, email, university, and password).
    • Uses Firebase Authentication (createUserWithEmailAndPassword()) to create a new user.
    • Stores the user’s details in Firestore (setDoc()).
  1. User Feedback & Redirection:
    • Displays a success message when the account is created.
    • Redirects the user to the login page (index.html) after 1 second.
    • Handles errors by displaying an error message in red.

This script ensures smooth user registration by managing authentication, data storage, and user feedback seamlessly.

3. youtube-search.js

This JavaScript code is a simple YouTube video search application using the YouTube Data API v3. It allows users to search for videos, view details of the first result, and navigate through search results using pagination.

Key Features

  1. Search for a YouTube Video
    • The function searchYouTube(query, pageToken) sends a request to the YouTube Search API.
    • It fetches video results based on the user’s query.
    • It retrieves only one video per search (maxResults=1).
    • If results exist, it extracts the videoId and fetches more details.
  1. Fetch Video Details
    • getVideoDetails(videoId) fetches details like title, views, likes, description, and creator using the YouTube Videos API.
    • It then calls displayResult(video) to show the video on the webpage.
  1. Display Video & Details
    • displayResult(video) dynamically generates and inserts an HTML block containing:
      • Embedded YouTube video (iframe)
      • Title (with a clickable YouTube link)
      • Creator’s name
      • View count
      • Like count
      • Shortened video description
  1. Pagination (Next & Previous Videos)
    • The API response includes nextPageToken and prevPageToken, used for pagination.
    • updateNavigationButtons() hides or shows the Next and Previous buttons accordingly.
    • Clicking Next or Previous calls searchYouTube() again with the respective page token.

Code Issues & Improvements

  • ⚠ API Key Exposure: The API key is hardcoded, which is a security risk. Instead, it should be stored in an environment variable (.env) or a backend server.
  • ⚠ Single Video Result: Currently, only one video is fetched per search. Increasing maxResults can provide more options.
  • ✅ Basic Error Handling: Errors are logged to the console but could be handled better (e.g., displaying user-friendly messages).
  • ✅ Minimalistic UI: The interface is clean but could be enhanced with a search input box, thumbnails, and better styling.

4. app.js

This file is a JavaScript script that powers a web-based search tool integrating both Google Custom Search and YouTube Search API. It allows users to input a search query and retrieve relevant results from Google and YouTube simultaneously.

Key Features & Functionality:

  1. Event Listener for Search Button:
    • Listens for clicks on a button with the ID searchBtn.
    • Retrieves the search query from an input field (ID: searchInput).
    • Clears previous search results and triggers both Google and YouTube searches.
  1. Google Custom Search Integration:
    • Uses Google's Custom Search API with a provided API key and search engine ID (GOOGLE_API_KEY and GOOGLE_CX).
    • Sends an API request to https://www.googleapis.com/customsearch/v1 with the search query.
    • If results are found, they are displayed as clickable links with snippets; otherwise, an error message is shown.
  1. YouTube Search Integration:
    • Queries YouTube Data API v3 to search for videos using the https://www.googleapis.com/youtube/v3/search endpoint.
    • Retrieves the most relevant video result (maxResults=1) and extracts the videoId.
    • If a valid video is found, another request is made to fetch detailed video statistics.
  1. Displaying YouTube Results:
    • Uses https://www.googleapis.com/youtube/v3/videos to fetch additional details like views, likes, creator, and description.
    • Displays an embedded YouTube video player along with metadata (title, creator, views, and description).
  1. Error Handling:
    • Catches errors during API requests and displays appropriate messages if no results are found or if the API call fails.

Security Issue:

  • The API keys are hardcoded, making them vulnerable to unauthorized use. Ideally, they should be stored securely on a backend server or use environment variables.

5. status_test.js

This JavaScript file, status_test.js, is designed to check the operational status of three services: Firebase Authentication, Google Custom Search API, and YouTube Data API. It does this by attempting to authenticate a user with Firebase and sending test queries to Google's and YouTube's APIs. The results are displayed on a webpage by updating HTML elements with status messages.

Key Functionalities:

  1. Firebase Authentication Status Check
    • Uses Firebase's signInWithEmailAndPassword method to attempt authentication with a predefined user.
    • Updates an HTML element with either "Operational" (if authentication succeeds) or "Service Down" (if it fails).
  1. Google API Status Check
    • Sends a test search query using Google’s Custom Search API.
    • If the response structure matches expectations, it marks the service as "Operational"; otherwise, it marks it as "Service Down".
  1. YouTube API Status Check
    • Sends a test search request using the YouTube Data API (v3).
    • Checks if the response is valid and updates the status accordingly.
  1. Event Listener for Automatic Checks
    • When the webpage loads (DOMContentLoaded), all three API status checks run automatically.

Potential Issues & Considerations:

  • Hardcoded API Keys & Credentials: The file contains hardcoded Firebase credentials, Google API keys, and a test user's login details, which is a major security risk. These should be stored securely (e.g., using environment variables or backend authentication).
  • Error Handling: While the file logs errors, it could benefit from better handling strategies, such as retry mechanisms or user notifications.
  • Rate Limits: Repeated API requests might hit Google’s and YouTube’s rate limits, causing temporary failures.

Use Case:

This script is useful for monitoring whether Firebase authentication, Google Search API, and YouTube API are operational in a web application. If any of these services are down, it provides a quick way to detect issues.
