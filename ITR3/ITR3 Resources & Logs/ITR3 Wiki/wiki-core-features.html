Custom Roadmap Generator

The Custom Roadmap Generator is one of the core features of StudyBase, allowing students to create personalized study plans based on their courses, learning style, and schedule.

Key Files

  • generate-roadmap.js - Core logic for roadmap generation
  • courses.json - Course data used for generating roadmaps

Implementation Details

The roadmap generator leverages a custom GPT model to analyze course content and create personalized study plans. It takes into account:

  • Course difficulty
  • Student learning preferences
  • Time constraints
  • Topic dependencies

The generate-roadmap.js file contains several key functions:

  • generateRoadmap(courseId, preferences) - Main function to create a roadmap
  • analyzeCourseContent(courseId) - Extracts course structure and content
  • createStudyPlan(courseContent, preferences) - Creates the actual study plan
  • renderRoadmap(roadmapData) - Renders the roadmap in the UI

Custom Course Search

The Custom Course Search feature allows students to find courses and professors based on various criteria, making it easier to plan their academic journey.

Key Files

  • courses.js - Main logic for course search and filtering
  • courses.html - UI for course search
  • courses.css - Styling for course search interface
  • courses.json - Course data
  • courseProf.json - Course-Professor relationship data

Implementation Details

The course search functionality provides filters for:

  • Course level
  • Department
  • Professor ratings
  • Schedule availability
  • Keywords in course descriptions

Key functions in courses.js include:

  • searchCourses(query, filters) - Main search function
  • filterByProfessor(courses, professorId) - Filter courses by professor
  • filterByDepartment(courses, departmentId) - Filter by department
  • renderCourseResults(courses) - Renders search results

Quiz Generator

The Quiz Generator allows students to create custom quizzes based on their course materials, helping them test their knowledge and prepare for exams.

Key Files

  • generate-quiz.js - Core logic for quiz generation
  • quiz.html - UI for quiz taking
  • quiz.css - Styling for quiz interface

Implementation Details

The quiz generator uses a custom GPT model to analyze course content and generate relevant questions. Features include:

  • Multiple choice questions
  • True/False questions
  • Short answer questions
  • Difficulty adjustment
  • Topic focus

Key functions in generate-quiz.js include:

  • generateQuiz(courseId, topics, questionCount, difficulty) - Main quiz generation function
  • createMultipleChoiceQuestion(topic, difficulty) - Creates MC questions
  • createTrueFalseQuestion(topic, difficulty) - Creates T/F questions
  • createShortAnswerQuestion(topic, difficulty) - Creates short answer questions
  • scoreQuiz(answers, quizData) - Scores completed quizzes

Professor Reviews

The Professor Reviews feature provides students with valuable insights into professors' teaching styles, course difficulty, and overall ratings.

Key Files

  • rateMyProfessor.js - Server component for RateMyProfessor integration
  • rmp-client.js - Client-side integration with RateMyProfessor API
  • rate-course-experience.html - UI for rating courses
  • rate-course-experience.js - Logic for course ratings

Implementation Details

The professor review system combines data from multiple sources:

  • RateMyProfessor external API
  • Internal user reviews
  • Course difficulty ratings

Key functions in the related files include:

  • getProfessorRatings(professorId) - Gets ratings from RMP
  • getUserReviews(professorId) - Gets user-submitted reviews
  • submitReview(professorId, courseId, rating, comment) - Submits a new review
  • calculateAverageRating(professorId) - Calculates overall rating
