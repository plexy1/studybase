YouTube API Integration

StudyBase integrates with the YouTube API to provide students with relevant educational content and supplementary videos for their courses.

Key Files

  • youtube-search.js - Core logic for YouTube API integration

Implementation Details

The YouTube API integration allows for:

  • Searching for educational videos related to course topics
  • Filtering results by relevance, rating, and upload date
  • Embedding videos directly in the study interface
  • Saving videos to study lists

Key functions in youtube-search.js include:

  • searchYouTube(query, maxResults) - Main search function
  • filterVideoResults(videos, filters) - Filters search results
  • embedVideo(videoId, elementId) - Embeds a video in the UI
  • saveVideoToStudyList(videoId, listId) - Saves a video for later reference

API Endpoint:

https://www.googleapis.com/youtube/v3/search

Custom GPT API Integration

StudyBase leverages a custom GPT model to provide personalized academic recommendations, generate quizzes, and create study roadmaps.

Key Files

  • generate-roadmap.js - GPT integration for roadmap generation
  • generate-quiz.js - GPT integration for quiz generation
  • generate-flashcards.js - GPT integration for flashcard creation
  • generate-test.js - GPT integration for comprehensive test generation
  • test-gpt.js - Testing module for GPT functionality

Implementation Details

The custom GPT model is fine-tuned for educational content and can:

  • Analyze course materials to extract key concepts
  • Generate relevant questions at different difficulty levels
  • Create personalized study plans based on learning preferences
  • Provide explanations for complex topics

Common functions across GPT-related files include:

  • callGptApi(prompt, parameters) - Makes API calls to the GPT endpoint
  • processGptResponse(response) - Processes and formats GPT responses
  • generatePrompt(data, template) - Creates context-specific prompts

API Configuration:

// Basic GPT API call structure
const callGptApi = async (prompt, parameters = {}) => {
  const response = await fetch('https://api.openai.com/v1/completions', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${API_KEY}`
    },
    body: JSON.stringify({
      model: 'custom-studybase-model',
      prompt,
      max_tokens: parameters.maxTokens || 500,
      temperature: parameters.temperature || 0.7,
      top_p: parameters.topP || 1,
      frequency_penalty: parameters.frequencyPenalty || 0,
      presence_penalty: parameters.presencePenalty || 0
    })
  });
  return await response.json();
};

Firebase & Cloud Firestore Integration

StudyBase uses Firebase and Cloud Firestore for authentication, data storage, and real-time updates.

Key Files

  • firebaseauth.js - Firebase authentication
  • Various JavaScript files that interact with Firestore for data storage

Implementation Details

Firebase integration provides:

  • User authentication with email/password and Google accounts
  • Storage of user profiles, preferences, and study data
  • Real-time updates for collaborative features
  • Cloud functions for server-side processing

Key functions in firebaseauth.js include:

  • initializeFirebase() - Sets up Firebase connection
  • signInWithEmailAndPassword(email, password) - Email/password authentication
  • signInWithGoogle() - Google authentication
  • createUserAccount(email, password, userData) - Creates new user accounts
  • getUserProfile(userId) - Retrieves user profile data

Firebase Configuration:

// Firebase initialization
const firebaseConfig = {

  messagingSenderId: "MESSAGING_SENDER_ID",
  appId: "APP_ID",
  measurementId: "MEASUREMENT_ID"
};

// Initialize Firebase
firebase.initializeApp(firebaseConfig);

RateMyProfessor API Integration

StudyBase integrates with the RateMyProfessor API to provide students with professor ratings and reviews directly within the application.

Key Files

  • rateMyProfessor.js - Server component for RateMyProfessor integration
  • rmp-client.js - Client-side integration with RateMyProfessor API

Implementation Details

The RateMyProfessor integration allows for:

  • Viewing professor ratings within course listings
  • Searching for professors by name, department, or rating
  • Accessing detailed reviews and comments
  • Comparing professors teaching the same course

Key functions in rmp-client.js include:

  • searchProfessors(query) - Searches for professors
  • getProfessorDetails(professorId) - Gets detailed professor information
  • getProfessorRatings(professorId) - Gets professor ratings
  • renderProfessorCard(professorData) - Renders professor information in the UI

Server Setup:

// RateMyProfessor server component
const express = require('express');
const { RateMyProfessorAPI } = require('ratemyprofessor-api');
const app = express();

app.get('/api/professor/search', async (req, res) => {
  try {
    const { query } = req.query;
    const results = await RateMyProfessorAPI.searchTeacher(query);
    res.json(results);
  } catch (error) {
    console.error(error);
    res.status(500).json({ error: 'Failed to search professors' });
  }
});

app.get('/api/professor/:id', async (req, res) => {
  try {
    const { id } = req.params;
    const professor = await RateMyProfessorAPI.getTeacher(id);
    res.json(professor);
  } catch (error) {
    console.error(error);
    res.status(500).json({ error: 'Failed to get professor details' });
  }
});

const PORT = process.env.PORT || 3000;
app.listen(PORT, () => console.log(`Server running on port ${PORT}`));
