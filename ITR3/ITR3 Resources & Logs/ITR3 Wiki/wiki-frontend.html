Main Pages

The main pages form the core navigation structure of the StudyBase application.

index.html / index.css

The landing page of the application that introduces users to StudyBase's features.

Components:

  • Hero section with introduction
  • Feature highlights
  • User testimonials
  • Quick access to main features
  • Call to action for sign-up/sign-in

Styling: Uses index.css for custom styling with a clean, modern UI focused on highlighting key features.

status.html / status.css

Dashboard showing a student's progress, upcoming deadlines, and study recommendations.

Components:

  • Progress overview cards
  • Study time graphs
  • Upcoming deadlines section
  • Personalized recommendations
  • Quick action buttons

Styling: Uses status.css for a dashboard-style interface with data visualizations and progress indicators.

communities.html / communities.css

Page for finding and interacting with study groups and course communities.

Components:

  • Community search and filters
  • Community cards with member counts
  • Discussion board previews
  • Create community form
  • Recommended communities

Styling: Uses communities.css for social media-inspired interfaces with emphasis on user interaction.

Course-Related Pages

These pages focus on course discovery, content, and assessment.

courses.html / courses.css

Central hub for browsing, searching, and filtering available courses.

Components:

  • Search bar with advanced filters
  • Course cards with key information
  • Department/subject filters
  • Professor rating indicators
  • Pagination controls

Key JavaScript: courses.js handles the search functionality, filtering, and data presentation.

quiz.html / quiz.css

Interface for taking generated quizzes and viewing results.

Components:

  • Question cards with various formats
  • Timer display
  • Progress indicator
  • Answer submission controls
  • Results and analysis view

Key JavaScript: generate-quiz.js provides the backend logic for quiz generation, while the UI is handled in the HTML/CSS.

search-topic.html / search-topic.css

Specialized search interface for finding specific topics across courses.

Components:

  • Topic search bar with auto-suggestions
  • Filter controls for narrowing results
  • Topic cards with preview content
  • Related topics suggestions
  • Save/bookmark controls

Key JavaScript: search-topic.js manages the search logic and API integration with various content sources.

rate-course-experience.html

Form for students to provide feedback on courses they've completed.

Components:

  • Rating scales for various aspects
  • Comment sections for detailed feedback
  • Course selection dropdown
  • Professor evaluation section
  • Submission controls

Key JavaScript: rate-course-experience.js handles form validation and submission to the backend.

User Account Pages

Pages related to user account management, history, and personalization.

account.html / account.css

User profile and account settings page.

Components:

  • Profile information display
  • Account settings form
  • Notification preferences
  • Learning preferences
  • Connected services management

Styling: account.css provides a clean, form-based interface with clear section divisions.

create-account.html / create-account.css

Registration form for new users.

Components:

  • Registration form with validation
  • Social login options
  • University selection
  • Initial preferences setup
  • Terms and conditions acceptance

Key JavaScript: firebaseauth.js manages the authentication process.

history.html / history.css

Comprehensive view of a user's activity and progress history.

Components:

  • Timeline of activities
  • Study session logs
  • Quiz results history
  • Course progress tracking
  • Achievement displays

Key JavaScript: test-history.js manages history retrieval and display formatting.

Style System

StudyBase implements a consistent style system across all pages for visual coherence and better user experience.

Key Style Files

  • generalUI.css - Shared components and base styles used across the application
  • Individual page CSS files for page-specific styling

Design Elements

Color Palette

Primary Blue #3498db
Success Green #2ecc71
Error Red #e74c3c
Warning Yellow #f39c12
Dark Blue #34495e

Typography

The application uses a consistent typography system:

  • Primary font: Segoe UI, Tahoma, Geneva, Verdana, sans-serif
  • Heading sizes: 2rem, 1.75rem, 1.5rem, 1.25rem
  • Base font size: 16px
  • Line height: 1.6

Components

Common UI components implemented across the application:

  • Buttons (primary, secondary, danger, success)
  • Form controls (inputs, selects, checkboxes, radios)
  • Cards for displaying grouped content
  • Navigation bars (top and side)
  • Modals and dialogs
  • Tabs and accordions
  • Alert and notification components

Responsive Design

The application is designed to be responsive across devices:

  • Mobile-first approach
  • Breakpoints at 576px, 768px, 992px, and 1200px
  • Flexible grid system
  • Collapsible navigation for smaller screens
